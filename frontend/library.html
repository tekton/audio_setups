        Your layouts

        Export all saves every layout in this browser to one JSON file. Import adds layouts from a file (one layout, an Export all file or a Full backup) as new copies; a Full backup also restores its device and port types. Clear all layouts deletes them (export first if you want a copy).

        System reset

        Clears every custom device type and port type you've added, back to the built-in defaults. Your saved layouts are not touched.
